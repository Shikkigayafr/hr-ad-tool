# HR → AD Панель (Эвостор)

Веб-приложение на Flask для управления пользователями в Active Directory.
Цель: чтобы HR/руководители могли создавать пользователей в AD (для последующей синхронизации с СБИС), не заходя на сервер AD.

## Текущий статус
- Сделана авторизация (сессии, защита страниц).
- Сделано разграничение прав (Админ может всё, HR — только своих стажеров).
- Сделана имитация БД (SQLite) для тестов.
- В `ad_utils.py` написан скрипт подключения к AD через ldap3, но сейчас он работает в режиме `DRY_RUN=true` (заглушка).
- Сделан адаптивный дизайн (папка static/style.css).

## Что нужно сделать дальше (NEXT STEPS)
1. Перенести проект на тестовую ВМ (Proxmox), которая видит контроллер домена.
2. В файле `.env` поменять `DRY_RUN=false` и прописать реальные IP, логин и пароль сервисной учетки AD.
3. Протестировать реальное создание пользователя в AD (OU=NewUsers).
4. Настроить удаление и повышение (смену групп) реального пользователя в AD через ldap3.
5. (В будущем) Настроить синхронизацию групп AD с ролями в СБИС.

## Как запустить (локально)
1. `python -m venv .venv`
2. `.venv/Scripts/python.exe -m pip install -r requirements.txt`
3. Создать `.env` (см. пример в ad_utils.py)
4. `.venv/Scripts/python.exe -m flask --app app init-db`
5. `.venv/Scripts/python.exe app.py`
