# HR → AD Панель (Эвостор)

Веб-приложение на Flask для управления пользователями в Active Directory.
Цель: чтобы HR/руководители могли создавать пользователей в AD (для последующей синхронизации с СБИС), не заходя на сервер AD.

## Текущий статус
- Сделана авторизация (сессии, защита страниц).
- Сделано разграничение прав (Админ может всё, HR — только своих стажеров).
- Сделана имитация БД (SQLite) для тестов.
- В `ad_utils.py` написан скрипт подключения к AD через ldap3, но сейчас он работает в режиме `DRY_RUN=true` (заглушка).
- Сделан адаптивный дизайн (папка static/style.css).

## Что нужно сделать дальше (NEXT STEPS)
1. Перенести проект на тестовую ВМ (Proxmox), которая видит контроллер домена.
2. В файле `.env` поменять `DRY_RUN=false` и прописать реальные IP, логин и пароль сервисной учетки AD.
3. Протестировать реальное создание пользователя в AD (OU=NewUsers).
4. Настроить удаление и повышение (смену групп) реального пользователя в AD через ldap3.
5. (В будущем) Настроить синхронизацию групп AD с ролями в СБИС.

## Как запустить (локально)
1. `python -m venv .venv`
2. `.venv/Scripts/python.exe -m pip install -r requirements.txt`
3. Создать `.env` (см. пример в ad_utils.py)
4. `.venv/Scripts/python.exe -m flask --app app init-db`
5. `.venv/Scripts/python.exe app.py`

# HR → AD Панель (Эвостор)

Веб-приложение для управления пользователями Active Directory. Позволяет HR-менеджерам создавать учетные записи без прямого доступа к серверу AD.

## 🚀 Реализованный функционал

### Бэкенд (Flask + SQLite)
* **Авторизация и безопасность**: Хеширование паролей, защита от брутфорса (бан на 30 минут после 5 неудачных попыток).
* **Роли (RBAC)**: Админ (видит всё), HR (создает только стажеров своего отдела), Глава отдела.
* **Интеграция с AD**: Настроен модуль `ldap3` (с поддержкой `DRY_RUN` для тестирования без реального сервера).
* **Журнал аудита (Логи)**: Запись всех действий (создание, повышение, удаление) с разграничением видимости по ролям.
* **Экспорт в CSV**: Выгрузка списка сотрудников с корректной кодировкой для Excel.
* **Real-time уведомления**: WebSockets (Socket.IO) для мгновенного обновления ленты событий у всех открытых вкладок.

### Фронтенд (Vanilla JS + CSS3)
* **Современный UI**: Темная/светлая тема (с сохранением в localStorage), Glassmorphism, плавные анимации.
* **Адаптивность**: Мобильная версия (таблица превращается в карточки).
* **UX-фишки**: 
  * Скелетоны загрузки (Skeleton UI).
  * Умная валидация форм (сложность пароля, проверка email).
  * Кастомные тосты (всплывающие уведомления) с иконками и звуком.
  * Поиск по таблице в реальном времени.
  * Личный кабинет (смена аватара, имени, пароля).
  * Пасхалки (скрытые соцсети разработчика в футере).

## 🛠️ Технологии
* Python (Flask, SQLAlchemy, Flask-SocketIO)
* LDAP (ldap3)
* SQLite (тестовая БД)
* HTML5, CSS3, JavaScript (Chart.js для графиков)

## ⚙️ Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Создать БД: `flask --app app init-db`
3. Запустить: `python app.py`

*(Не забудьте настроить файл `.env` для подключения к реальному AD).*
