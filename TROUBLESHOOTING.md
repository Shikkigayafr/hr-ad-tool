# Журнал решенных проблем (Troubleshooting)

В этом файле собраны ошибки, с которыми я столкнулся при разработке панели HR → AD, и способы их решения.

## 1. Сессия слетает при переходе на страницу `/create` или `/employees`
**Симптом:** При клике на ссылку страница открывается на секунду и перекидывает на главную.
**Причина:** В Flask настроены политики безопасности куки (SameSite), из-за чего браузер не передавал сессию, и срабатывала защита (редирект на главную).
**Решение:** Добавить в `app.py` конфигурацию для куки:
```python
app.config['SESSION_COOKIE_SAMESITE'] = 'Lax'
app.config['SESSION_COOKIE_SECURE'] = False 
app.config['SESSION_COOKIE_HTTPONLY'] = True
```
2. Ошибка UNIQUE constraint failed: employee.login
Симптом: При создании пользователя Flask падает с ошибкой базы данных SQLite.
Причина: Скрипт сначала записывал пользователя в локальную БД, а потом в AD. Если создание в AD падало (например, из-за пароля), в БД оставалась «фантомная» запись. При повторной попытке SQLite выдавал ошибку дубликата.
Решение: Поменять порядок в app.py (сначала создаем в AD, и только если успешно — пишем в базу).

3. Ошибка unwillingToPerform (код 53) при смене пароля
Симптом: Ошибка пароля: {'result': 53, 'description': 'unwillingToPerform'...}
Причина: Active Directory запрещает менять пароли по незащищенному протоколу LDAP (порт 389).
Решение: Перейти на LDAPS (порт 636). В ad_utils.py изменить подключение на использование use_ssl=True и порт 636.

4. Ошибка WinError 10054 (Socket ssl wrapping error)
Симптом: Соединение с AD по LDAPS обрывается при попытке установить SSL.
Причина: На контроллере домена не было валидного SSL-сертификата.
Решение:

Создать самоподписанный сертификат через PowerShell:
New-SelfSignedCertificate -DnsName "WIN-0NEPP7V4NH4.evostore.local", "WIN-0NEPP7V4NH4" -CertStoreLocation cert:\LocalMachine\My

Скопировать этот сертификат из папки «Личное» в «Доверенные корневые центры сертификации» через certlm.msc.

В коде использовать Tls(validate=ssl.CERT_NONE).

5. Ошибка insufficientAccessRights (код 50) при создании пользователя или группы
Симптом: Ошибка создания: ... INSUFF_ACCESS_RIGHTS или Пользователь создан, но не в группе.
Причина: Сервисной учетке svc_hr не хватало прав на создание пользователей в определенных OU или на изменение групп.
Решение: Выдать права через dsacls на виртуалке с AD:

Для сброса паролей в NewUsers: dsacls $ouDn /G "${svcUser}:CA;Reset Password;user" /I:S

Для добавления в группы: dsacls $groupsDn /G "${svcUser}:WP;member" /I:S

Для создания пользователей в отделах: dsacls $departmentsDn /G "${svcUser}:CC;user" /I:S

6. Ошибка entryAlreadyExists (код 68)
Симптом: Ошибка создания: {'result': 68, 'description': 'entryAlreadyExists'...}
Причина: Пользователь с таким логином уже существует в AD (возможно, остался от прошлых тестов).
Решение: Сменить логин при создании, либо удалить старых тестовых пользователей через PowerShell:
Get-ADUser -Filter * -SearchBase "OU=NewUsers,DC=evostore,DC=local" | Remove-ADUser -Confirm:$false


## 7. Saby: Ошибка "Убедитесь, что было передано поле \"organization\""
**Симптом:** При вызове `sabyEmployee.UpdatePosition` Saby возвращает 500 и просит `organization`.
**Причина:** Поле `organization` должно быть передано **в двух местах**: на уровне `filter` (для поиска) и внутри `position` (для записи).
**Решение:** В запросе `sabyEmployee.UpdatePosition` передавать `organization` и в `filter`, и в `position`.

## 8. Saby: Ошибка "Не удалось найти должность"
**Симптом:** Saby не находит должность по названию «Сотрудник».
**Причина:** В справочнике должностей Saby нет должности с таким названием.
**Решение:** Использовать существующие должности из `sabyPosition.List` (например, «Менеджер» с UUID `305d7061-...`).

## 9. Saby: Отдел не привязывается (висит в корне)
**Симптом:** API возвращает 200, но в интерфейсе сотрудник висит в корне.
**Причина:** API работает с **кадровой структурой**, а визуальное дерево (управленческая структура) управляется только вручную (перетаскиванием).
**Решение:** Оставить ручное перетаскивание (5 секунд) или использовать кадровую структуру (если HR смотрит её).
