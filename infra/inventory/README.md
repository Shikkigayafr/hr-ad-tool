# Инвентаризация ПК

Два скрипта: один запускается **на каждом ПК** и пишет свой файл, второй собирает общий отчёт. Подходит для офиса, где компьютеры ещё не в домене: удалённый доступ не нужен.

Скрипты **только читают** данные (железо, версия и редакция Windows, статус лицензии, TPM, сеть, список программ) и ничего не меняют.

## Как пользоваться

1. Положите папку `infra\inventory` на общую сетевую папку (например `\\server\inventory$`) с правом записи для сотрудников или администратора.
2. На каждом ПК запустите `Run-Inventory.bat` двойным кликом (лучше **от администратора** — тогда определятся TPM и Secure Boot; без админа они будут «нет данных»). Для записи прямо в общую папку отредактируйте строку `set OUTPUT=` в `.bat`.
3. Каждый ПК создаёт `<ИМЯ_ПК>.json` (повторный запуск обновляет файл). Если общая папка недоступна, файл сохранится рядом со скриптом.
4. Соберите отчёт:
   ```powershell
   .\Merge-Inventory.ps1 -InputPath \\server\inventory$
   ```
   Получится папка `report`: `summary.txt` (сводка), `computers.csv`, `programs.csv`, `programs_by_popularity.csv`. CSV открываются в Excel сразу (разделитель `;`, кодировка UTF-8 с BOM).

## Что в сводке
Сколько ПК в домене и не в домене; сколько с Windows **Home** (в домен не вводится) и на Windows 10 (поддержка закончилась 14.10.2025); сколько готово к Windows 11 (по ОЗУ, диску, UEFI и TPM 2.0; процессор не проверяется); ПК с ОЗУ меньше 8 ГБ и почти полным диском; статус лицензии и её тип (для учёта); самые распространённые программы — основа для списка в `infra/deploy/software.json`.

## Примечания
* Статус лицензии — справочная информация для учёта, скрипт ничего не активирует.
* В JSON попадают имя ПК, пользователь, серийный номер, IP/MAC и список программ — храните папку с отчётами в доступе только для администраторов.
* Файлы `.ps1` сохранены в UTF-8 **с BOM** — это нужно Windows PowerShell 5.1, иначе кириллица портится. При правке сохраняйте так же (тест `tests/test_infra_files.py` это проверяет).
